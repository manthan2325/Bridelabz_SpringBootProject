# Bridgelabz_Java

A SpringBoot Project Created with RESTAPI methods and use of Controller,Service and Repository layer and also various other methods of RESTAPIS.

## Repository Structure
- `main` : this README with daily task updates
- `develop` : all the folders merged into the develop structure

## Project Work

- I used various Methods like @RequestParam, @PathVariable,@GetMapping,@PostMapping and many other methods.
- Passed data in various formats through POSTMAN and passed it through Service, Controller, and Repository layers.
